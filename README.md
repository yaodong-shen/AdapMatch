# AdapMatch

Official implementation of **AdapMatch: Adaptive Bias Decoupling for Semi-Supervised Partial Label Learning under Unknown Class Distributions**.

**Accepted at NeurIPS 2026 (Main Track, Poster).**

Yuheng Jia*, Yaodong Shen*, Jiahao Jiang, Hui Liu, and Junhui Hou†  
*Equal contribution. †Corresponding author.

[Paper](https://openreview.net/forum?id=eAtYtntHfU) · [Conference page](https://neurips.cc/virtual/2026/loc/sydney/poster/150939) · [Code](https://github.com/yaodong-shen/AdapMatch/tree/main/AdapMatch)

AdapMatch adaptively decouples sample selection bias and label disambiguation bias for semi-supervised partial label learning under unknown class distributions.
